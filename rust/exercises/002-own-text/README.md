# 002 把借来的文字留成自己的

依据：第 1 题已通过。这题只多一件事，就是你刚问过的：`&str` 是借来看的，不会自动变成 `String`。

打开 `src/lib.rs`，只改 `store`。`read` 已经写好。

`store` 收到一段借来的文字 `&str`，返回 `Note`。`Note` 里面要放一份你自己拥有的 `String`。做法和上一题的 `"waiting".to_string()` 一样。

调用方之后还会改原来的文字，所以 `Note` 里必须是另一份。例如原来是 `"ping"`，存完后再在后面加上 `!`，`read` 仍然得到 `"ping"`。

做完后在本目录运行 `cargo test`。2 个测试都通过就完成。
