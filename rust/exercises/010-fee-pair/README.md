# 010 把两个数字放进一组

依据：第 9 题自己写完了。集合还没练过，这一题只加 `Vec`。

打开 `src/lib.rs`，只改 `pair`。测试不要动。

`Vec<u32>` 是一组数字。`vec![1, 2]` 会做出一组，里面按顺序是 1 和 2。

用 `vec!` 把 `left` 和 `right` 按这个顺序放进去返回。不要写死成 1 和 2。

| `left` | `right` | 应返回 |
|--------|---------|--------|
| `1` | `2` | `vec![1, 2]` |
| `0` | `0` | `vec![0, 0]` |

做完后在本目录运行 `cargo test`。2 个测试都通过就完成。
