# 013 把每个数字加起来

依据：第 12 题自己写完了。`Vec` 还只会按位置取一个，这一题只加 `for`。

打开 `src/lib.rs`，只改 `total`。测试不要动。

先放一个会变的和，从 0 开始：`let mut sum = 0;`。然后用 `for` 取出每一个数字，加进 `sum`：

```rust
for fee in fees {
    sum += fee;
}
```

加完后返回 `sum`。空的一组没有数字可加，和仍然是 0。

| `fees` | 应返回 |
|--------|--------|
| `vec![1, 2, 3]` | `6` |
| `vec![]` | `0` |
| `vec![0, 5]` | `5` |

做完后在本目录运行 `cargo test`。3 个测试都通过就完成。
