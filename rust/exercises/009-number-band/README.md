# 009 数字分两档

依据：第 8 题提示里给过完整三支 `match`，你问过为什么还要 `Some(_)`。这一题还是只练模式后面的 `if`，输入改成一个数字，不再包在 `Option` 里。

打开 `src/lib.rs`，只改 `band_of`，把 `todo!()` 换成 `match`。测试不要动。

先写带 `if` 的那一支。它不计入覆盖，所以后面还要一支不带 `if` 的 `_`，接住其余数字。

```rust
n if n < 10 => "low",
```

| 输入 | 应返回 |
|------|--------|
| `0` | `"low"` |
| `9` | `"low"` |
| `10` | `"high"` |
| `12` | `"high"` |

做完后在本目录运行 `cargo test`。4 个测试都通过就完成。
