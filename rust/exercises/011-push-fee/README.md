# 011 往末尾放一个数字

依据：第 10 题自己写完了。`Vec` 还只会新建，这一题只加 `push`。

打开 `src/lib.rs`，只改 `with_fee`。测试不要动。

`push` 会改这组数字，所以参数要写成 `mut fees`。然后调用 `fees.push(fee)`，把 `fee` 放到末尾。放完后把这组返回。

| `fees` | `fee` | 应返回 |
|--------|-------|--------|
| `vec![1]` | `2` | `vec![1, 2]` |
| `vec![]` | `0` | `vec![0]` |

做完后在本目录运行 `cargo test`。2 个测试都通过就完成。
