# 008 先匹配，再看 if

依据：第 7 题的提示给过完整两支 `match`，你说不会写条件匹配。这一题只加一件事：模式后面写 `if`。

打开 `src/lib.rs`，只改 `kind_of`，把 `todo!()` 换成 `match`。测试不要动。

在模式后面可以加条件。先对上样子，再看 `if` 是否成立。`0` 要单独接住，所以这一支写在前面：

```rust
Some(n) if n == 0 => "zero",
```

条件不成立时，这一支就跳过，继续看下面的分支。`Some` 里不是 `0` 的，用 `Some(_)`。`None` 单独一支。

| 样子 | 应返回 |
|------|--------|
| `Some(0)` | `"zero"` |
| `Some(12)` | `"positive"` |
| `None` | `"missing"` |

做完后在本目录运行 `cargo test`。3 个测试都通过就完成。
