# 014 借来看，加完还在

依据：第 13 题自己写完了。上一题会把整组 `Vec` 拿走，这一题只改成借用。

打开 `src/lib.rs`，只改 `total`。测试不要动。

参数已经是 `&[u32]`：借来的一组数字，不是你拥有的 `Vec`。加法和上一题一样，从 `let mut sum = 0;` 开始。

`for fee in fees` 每次拿到的是 `&u32`。用 `*fee` 取出数字再加：

```rust
for fee in fees {
    sum += *fee;
}
```

加完后返回 `sum`。调用方之后还能用原来的那组。

| 调用 | 应返回 |
|------|--------|
| `total(&[1, 2, 3])` | `6` |
| `total(&[])` | `0` |
| `total(&fees)`，其中 `fees` 是 `vec![1, 2]` | `3`，并且 `fees` 仍是 `vec![1, 2]` |
