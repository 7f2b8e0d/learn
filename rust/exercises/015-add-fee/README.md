# 015 借来改原来的那组

依据：第 14 题自己写完了。上一题只能借来看，这一题只加可变借用。

打开 `src/lib.rs`，只改 `add_fee`。测试不要动。

参数是 `&mut Vec<u32>`：可以改调用方原来的那组，不用把整组拿走，也不用再返回它。直接往末尾放：

```rust
fees.push(fee);
```

调用的地方写成 `add_fee(&mut fees, 2)`。`fees` 自己要是 `let mut fees`，才能借出可变借用。

| 调用前 | 调用 | 调用后 |
|--------|------|--------|
| `vec![1]` | `add_fee(&mut fees, 2)` | `vec![1, 2]` |
| `vec![]` | `add_fee(&mut fees, 0)` | `vec![0]` |

做完后在本目录运行 `cargo test`。2 个测试都通过就完成。
