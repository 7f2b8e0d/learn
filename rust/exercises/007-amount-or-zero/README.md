# 007 有数字就用数字，没有就用 0

依据：第 6 题是 AI 代写的，`Some` 和 `None` 还没自己写过。这一题还是只练这个 `match`，但不再拼 `String`。

打开 `src/lib.rs`，只改 `amount_or_zero`，把 `todo!()` 换成 `match`。测试不要动。

`balance` 只有两种样子：

| 样子 | 应返回 |
|------|--------|
| `Some(12)` | `12` |
| `Some(0)` | `0` |
| `None` | `0` |

`Some` 里面的数字直接返回，不要写死成 12。`None` 返回 `0`。

做完后在本目录运行 `cargo test`。3 个测试都通过就完成。
