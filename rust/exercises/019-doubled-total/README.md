# 019 每个数字先乘 2

依据：第 18 题自己写完了。`iter()` 还只会 `sum`，这一题只加 `map`。

打开 `src/lib.rs`，只改 `doubled_total`。`add` 已经写好。测试不要动。

`map` 对每个数字做同一件事，然后再 `sum()`。`|fee|` 是一个小函数，`fee` 是当前这个 `&u32`。乘法接受这个引用，不用写 `*`。

```rust
self.fees.iter().map(|fee| fee * 2).sum()
```

| 过程 | `doubled_total` |
|------|-----------------|
| 空账本先 `add(1)` 再 `add(2)` | `6` |
| 空账本，不调用 `add` | `0` |
