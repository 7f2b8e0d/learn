# 018 用 sum 把数字加起来

依据：第 17 题自己写完了。你问过 `iter()` 还能接方法，这一题只加 `sum`。

打开 `src/lib.rs`，只改 `total`。`add` 已经写好。测试不要动。

不用写 `for`。`iter()` 借出每个数字，`sum()` 把它们加起来。空的一组加出来是 0。

```rust
self.fees.iter().sum()
```
