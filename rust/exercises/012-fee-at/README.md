# 012 按位置取一个数字

依据：第 11 题自己写完了。`Vec` 还只会往里放，这一题只加 `get`。

打开 `src/lib.rs`，只改 `fee_at`。测试不要动。

`fees.get(index)` 得到 `Option<&u32>`。这个位置有数字是 `Some`，没有是 `None`。数字可以复制，用 `copied()` 把里面的引用变成 `u32`：

```rust
fees.get(index).copied()
```

位置从 0 开始。`0` 是第一个，`1` 是第二个。

| `fees` | `index` | 应返回 |
|--------|---------|--------|
| `vec![10, 20]` | `0` | `Some(10)` |
| `vec![10, 20]` | `1` | `Some(20)` |
| `vec![10]` | `3` | `None` |

做完后在本目录运行 `cargo test`。3 个测试都通过就完成。
